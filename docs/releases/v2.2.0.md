# Camaleon v2.2.0 — AVIF encode (PNG/JPEG → AVIF)

**Date:** 2026-06-11  
**Tag:** `v2.2.0` (pending merge to `main`)  
**Wave:** Tier 3 Phase 3.2.0–3.2.2

## Summary

Camaleon **2.2.0** completes the **inbound AVIF pair** with **PNG → AVIF** and **JPEG → AVIF** (Phases 3.2.1–3.2.2), backed by a new **`transmutador_avif_encode`** Wasm module (Phase 3.2.0 spike). **19 active conversion tools** — full AVIF encode + decode matrix in-browser.

Planning for **Tier 3.3 SVG** rasterize is documented in `docs/planning/tier3_3_svg_analysis.md` (no user-facing SVG tools in this release).

## Categories

| Tag | Scope |
|-----|--------|
| **FEATURE** | PNG → AVIF, JPEG → AVIF; `transmutador_avif_encode` (ravif); quality + speed sliders |
| **ARCH** | Split decode/encode Wasm crates (NFR-7 — merged crate exceeded 3 MB) |
| **DOCS** | Encode spike results; Tier 3.3 SVG format science analysis |

## User-facing

- **New tools:** PNG → AVIF (`/transmute/png-to-avif`), JPEG → AVIF (`/transmute/jpg-to-avif`)
- **Sliders:** AVIF quality (1–100, default 60) and encoder speed (1–10, default 6)
- **Honesty:** Semantic alpha on PNG path; generational loss hint on JPEG → AVIF (NFR-8)
- **Onboarding:** updated to **19 conversion tools**

## Technical

### Engine (`motor_transmutacion` v1.6.0)

- New crate **`transmutador_avif_encode`** — ravif 0.13 encode-only (~1.67 MB Wasm)
- `transmutador_avif` decode unchanged (~1.90 MB Wasm)
- `OutputFormat::Avif` in `core_utils`
- `estimate_png_to_avif_size` / `estimate_jpg_to_avif_size` (full encode parity)
- Defaults: quality **60**, speed **6**

### Frontend

- Worker lazy-load `transmutador_avif_encode`; `encodeSource: "png" | "jpeg"`
- `post-resize-route` AVIF output path
- i18n EN/ES for both tools + spike-documented encode latency class
