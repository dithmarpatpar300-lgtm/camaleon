# Camaleon v3.6.0 — Resize Premium

**Date:** 2026-06-22
**Branch:** `dev`
**Tag:** `v3.6.0`
**Engine:** 1.6.0

## Summary

Major upgrade of the resize tools (`png-resize` and `jpg-resize`) — **Phase A through E** of the resize premium roadmap delivered in a single release. Adds filter selection (5 interpolation algorithms), upscale support (1–200%, advanced 400%), configurable JPEG quality on resize, target dimensions display, adaptive notices, and dedicated estimate exports.

## Highlights

### 5 resampling filters (Phase B)

- **Sharp (CatmullRom)** — new default. Industry-standard bicubic. Best balance of sharpness and speed.
- **Sharpest (Lanczos3)** — maximum detail, may produce halos on high-contrast edges. Original default, now advanced.
- **Smooth (Triangle)** — fast and artifact-free, suitable for thumbnails.
- **Pixel Perfect (Nearest)** — preserves hard edges, ideal for pixel art. Behind "Advanced" toggle.
- **Anti-alias (Gaussian)** — deliberate pre-blur for extreme downscaling. Behind "Advanced" toggle.
- Filter choice persists per tool; estimate re-runs on change.

### Downscale hardening (Phase A)

- Slider range: **1%–200%** (was 10%–100%).
- **Step: 1%** (was 5%) — precise control.
- **Presets: 25%, 33%, 50%, 66%, 75%** (was 25/50/75).
- Target dimensions display: `W×H → W'×H'` updates live with slider.
- Resize-specific notices: JPEG generational loss, extreme downscale warnings.

### Upscale support (Phase C)

- Upscale to **200%** with honesty guardrails.
- **Advanced scaling toggle** unlocks 201%–400% with filter-specific warnings:
  - Lanczos3 above 200%: ⚠ ringing artifacts
  - CatmullRom/Triangle/Gaussian: blur warning
  - Nearest: blocky replication warning
- Amber color coding for >100% values in slider and dimensions display.
- Upscale honesty notice: "No new detail is created — pixels are interpolated."

### JPEG quality control (Phase D)

- `jpg-resize` now has **two sliders**: resize scale + JPEG quality.
- Quality presets: 60%, 75%, 85%, 92%.
- Independent control — user chooses both dimensions and compression level.

### Estimate parity (Phase E)

- Dedicated `estimate_resize_png_size` / `estimate_resize_jpeg_size` Wasm exports.
- Faster estimate feedback on slider drag — parity with compress tools.

### Rust engine changes

- `transmutador_optimize` now exports:
  - `resize_png_with_filter(input, percent, filter_code)` / `resize_jpeg_with_filter(...)`
  - `resize_jpeg_with_filter_and_quality(input, percent, filter_code, quality)`
  - `estimate_resize_png_size(...)` / `estimate_resize_jpeg_size(...)`
- `filter_from_code()` maps 0=Nearest..4=Lanczos3
- New default: CatmullRom (was Lanczos3)
- `MAX_RESIZE_PERCENT` raised to 400 (was 100), parameter type `u16` (was `u8`)
