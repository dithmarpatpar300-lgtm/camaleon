# Camaleon v2.1.1 — AVIF → JPEG + animated preview UX

**Date:** 2026-06-11  
**Tag:** `v2.1.1`  
**Wave:** Tier 3 Phase 3.1.2 + UX hotfixes

## Summary

Camaleon **2.1.1** completes the outbound **AVIF pair** with **AVIF → JPEG** (Phase 3.1.2) and ships major **animated preview** improvements: off-thread frame warm-up, session cache, flicker-free scrubbing, and estimate-sync on the Transmute button. **17 active conversion tools.**

## Categories

| Tag | Scope |
|-----|--------|
| **FEATURE** | AVIF → JPEG (`assess_alpha`, quality + background, estimate with alpha hint) |
| **UX** | Frame preview worker; LRU RGBA cache; warm-up vs scrub overlay split; transmute blocked while stale estimate |
| **FIX** | Stable `fileBytes` identity (no re-decode on slider); monotonic warm-up progress |

## User-facing

- **New tool:** AVIF → JPEG (`/transmute/avif-to-jpg`) — quality slider, background flatten, lossy-on-lossy fidelity hint
- **Animated AVIF/GIF scrubber:** background frame decode, instant scrub after warm-up, no “Rendering preview…” flash
- **Transmute button:** shows “Updating estimate…” only when KB on screen is stale and recalculating

## Technical

### Engine (`motor_transmutacion` v1.5.1)

- `transmutador_avif`: `assess_alpha`, `transmutar_avif_a_jpg_*`, `estimate_avif_to_jpg_size`
- Integration + semantic-alpha contract tests
- `core_utils` wasm feature on AVIF crate for alpha export

### Frontend

- `frame-preview.worker.ts` + `frame-preview-cache.ts` — AVIF session off main thread, TTL + release on Transmute
- `RgbaFrameScrubber`, `use-coalesced-frame-paint`, `frame-rgba-cache`
- `transmuteReady` guard: `estimating && !cacheWarm && estimateDelta`
- Memoized `stagedFileBytes` in `TransmutationPanel`
