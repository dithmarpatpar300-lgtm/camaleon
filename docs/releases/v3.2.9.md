# Camaleon v3.2.9 — Universal cohorts, batch polish & image optimize

**Date:** 2026-06-19  
**Branch:** `main`  
**Tag:** `v3.2.9`  
**Engine:** 1.6.0 (`transmutador_optimize` crate added)

## Summary

Completes **Tier 3.6.1 Slice C** (mixed-format cohort picker), **Settings S7** batch prefs, **Tier 3.6.2** (ZIP delivery + GIF/TIFF/ICO per-row batch), and ships **Tier 4a** image optimize tools. Batch download UX is hardened: instant re-download from stored results, run cancellation on navigation, contextual cancel from home handoff.

## Changes

### Tier 3.6.1 Slice C — Universal mixed cohorts

- `UniversalCohortPicker.tsx` — one card per format group with “Choose output →”.
- `cohort-session.ts` — in-memory store (60 min TTL) for remaining cohorts after partial handoff.
- `universal-drop.ts` — full `cohorts[]` for mixed drops; respects `allowMultiDrop` and `mixedFormatPolicy`.
- `UniversalTransmutator.tsx` — mixed phase, handoff flow, session restore on mount.

### Settings S7 (remaining)

- `universalMultiDrop` toggle (default on).
- `mixedFormatPolicy`: cohort picker vs hint only (default picker).
- `batchDownloadMode`: individual files vs ZIP archive (default individual).
- Reset button alignment fixed in Batch & Universal section.

### Tier 3.6.2 — Batch ZIP & per-row pickers

- `batch-zip-export.ts` — client-side ZIP via `fflate`; delivery driven by Settings pref (no in-panel ZIP button).
- Batch allowlist extended: `gif-to-png`, `gif-to-jpg`, `tiff-to-png`, `tiff-to-jpg`, `ico-to-png`.
- `BatchRowIndexPicker`, `batch-per-row-options.ts` — frame/page/entry sliders per row.

### Tier 4a — Image optimization

- Rust crate `transmutador_optimize` — compress + resize for PNG/JPEG.
- Four tools registered: `png-compress`, `jpg-compress`, `png-resize`, `jpg-resize`.
- Worker routes, i18n EN/ES, `resizePercent` option in UI.

> **Note:** v3.2.9 shipped the crate and registry; **end-to-end activation** (prepare warmup, types, JPEG meta) landed in **v3.3.0** — see `docs/releases/v3.3.0.md`.

### Batch UX fixes

- Prepare/transmute fingerprint alignment — instant download when slider unchanged after prepare gate.
- `batch-stored-delivery.ts` — re-download from `item.result` without worker round-trip (ZIP mode switch).
- `activeRunIdRef` — cancel in-flight runs on unmount/navigation; no partial ZIP on abort.
- **Contextual cancel:** handoff from home → “Back to home”; drop on tool route → “Cancel batch” + dropzone.

## QA exit gate

1. Home → drop 4 PNG + 1 SVG → cohort picker → handoff PNG batch → Cancel → returns to `/`.
2. `/transmute/png-to-webp` → drop 4 files → Cancel → dropzone on same route.
3. Batch convert → Settings ZIP → Download again → single ZIP, no re-encode stall.
4. Navigate away mid-batch → no stray partial ZIP download.
5. `png-compress` / `jpg-resize` routes load Wasm and transmute locally.
