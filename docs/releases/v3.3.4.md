# Camaleon v3.3.4 — Settings + toasts, client storage & lane persistence

**Date:** 2026-06-20  
**Branch:** `main` (merged from `dev`)  
**Tag:** `v3.3.4`  
**Engine:** 1.6.0 (unchanged)

## Summary

Fixes **Settings drawer blocking/interaction** with floating toasts (HTML dialog inert subtree), introduces a **unified client storage module** with **factory-default seeding**, and eliminates **Convert/Optimize lane flash** on reload. Mobile offline notice moves to a **bottom dock** above toasts.

## Changes

### Settings + floating notices coexistence

- **`showModal()` inertness** — content outside `<dialog>` cannot receive clicks even when painted on top; bottom toasts **portal into** `.surface-modal-notices-slot` inside the open dialog.
- Top offline notice **hidden** while Settings is open (`body[data-modal-open]`); no overlap with drawer panel.
- Drawer scrim dismiss respects toast hit-test (`floating-notices-hit-test.ts`) — click toast actions without closing Settings.
- `modal-floating-notices-portal.ts` + `floating-notices-layer.ts` ref-count modal/toast holds.

### Mobile offline dock

- `useMobileViewport` — offline status on **bottom stack** (above toasts) on `<640px`; desktop keeps top-right pill.
- Sticky ToolBrowser toolbar gap preserved.

### Client storage module (`lib/storage/`)

- **`keys.ts`** — registry of all localStorage/cookie keys.
- **`factory-defaults.ts`** — single source of factory values for every Settings section + tools prefs.
- **`seed-storage.ts`** — bootstrap + `ClientStorageSeed` write full defaults on first visit (idempotent merge).
- Tool browser prefs consolidated under **`camaleon-user-settings-v1.tools`** (lane, tab, density); legacy `camaleon.tools.*` keys migrated.
- SSR cookies + bootstrap for lane/tab/density — **no pill flash** on F5.

### UX polish

- `HorizontalScrollFade` on ToolBrowser format tabs (mask veil on overflow).
- `data-scroll-behavior="smooth"` on `<html>` — silences Next.js scroll-behavior warning.
- Liquid pill lane control; factory reset persists explicit defaults (not empty `{}`).

## QA exit gate

1. Open Settings with offline toast visible → top notice hidden; bottom toast buttons **work**; Settings stays open.
2. Click scrim (not toast) → Settings closes.
3. Mobile: offline dock above bottom toasts; no toolbar collision.
4. Clear site data → reload → `camaleon-user-settings-v1` contains **all** factory sections.
5. Select Optimize → F5 → lane correct on first frame (no Convert flash).
6. `npm test` passes (147 tests).
