# Camaleon v3.9.1 — Smart Notice Recommendations

**Date:** 2026-06-24
**Branch:** `dev` → `main`
**Tag:** `v3.9.1`
**Engine:** 1.8.0

## Summary

The Notice Rail has been transformed from a passive message display into an intelligent recommendation engine. When a transmutation is suboptimal, actionable inline pills appear directly within the notice text, suggesting alternative tools with automatic file transfer.

## Highlights

### Actionable inline recommendation pills
- New `ActionInlinePill` component embeds clickable buttons directly inside notice text, following the same inline pattern as `BackgroundColorPill` in `TransparencyNotice`.
- Pills styled with `bg-accent-subtle text-accent mx-0.5` — noticeable but not competing with the primary "Transmutar" button.
- Arrow icon signals navigation (material design chip pattern).

### 5-rule smart recommendation engine
- **R1 — Lossy→lossless inflation**: Detects when a lossy source produces larger output in a lossless tool. Suggests `webp-to-jpg` or `jpg-compress`.
- **R2 — Lossless ceiling**: Informs when a file is already at its compression limit.
- **R3 — JPEG generational loss**: Warns about cumulative quality loss on re-encode, suggests PNG as intermediate master.
- **R4 — Alpha flatten**: Detects transparency being lost on JPEG output, suggests lossless preserve tools by format.
- **R5 — Size increase**: When output is >5% larger, suggests adjusting options or alternative tool.

### Cross-tool navigation with file transfer
- Clicking a recommendation pill stages the current file via `stageFileHandoffFromFile()` and navigates to the target tool.
- The file is pre-loaded in the destination tool — zero re-drops needed.

### Deduplication pipeline
- 6 suppression rules filter out redundant fidelity notices when recommendations are active.
- Recommendation→recommendation dedup prevents R5 from firing when R1 or R3 already covers the problem.
- Max visible notices increased from 2 to 3.
