# Camaleon v3.2.8 — Batch selection default & adaptive toasts

**Date:** 2026-06-18  
**Branch:** `dev`  
**Tag:** `v3.2.8` (when promoted)  
**Engine:** 1.6.0 (unchanged)

## Summary

Settings **S7 (Priority A)**: choose whether batch rows start **all selected** or **none selected** on load. **Adaptive toasts** fix bottom clipping on long messages (e.g. universal unsupported batch hint).

## Changes

### Settings S7 — Priority A

- `batch-universal-prefs.ts` — `defaultSelection: "all" | "none"` (default all).
- `BatchUniversalSettingsSection` in Settings drawer.
- `batchItemsFromFiles()` reads pref when creating batch workspace rows.

### Adaptive toasts

- No viewport height cap for 1–3 toasts — cards grow with content.
- `line-clamp: 3` on message text — sensible max without giant cards.
- Queue peek (4th+ toast) uses `TOAST_SLOT_MAX_PX` for bounded scroll.

## QA exit gate

1. Settings → Batch & Universal → None → drop 3 PNG on png-to-jpg → no rows selected initially.
2. Drop 4 SVG on universal → toast fully visible, no bottom clip.
3. Four rapid toasts → peek band still works.

## Not in this release

- Universal multi-drop toggle, mixed-format policy (Slice C prep)
- Slice C cohort picker
