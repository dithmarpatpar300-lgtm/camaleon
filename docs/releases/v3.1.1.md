# Camaleon v3.1.1 — Universal Transmutator + handoff fix (Tier 3.5 phase)

**Date:** 2026-06-11  
**Branch:** `dev`  
**Tag:** `v3.1.1`  
**Engine:** 1.6.0 (unchanged)

## Summary

**v3.1.1** ships the **Universal Transmutator** on the home page (Tier 3.5 planning phase) with a reliable file handoff into existing tool routes, visual polish, and app version alignment at **3.1.x** (not 3.5.x).

## Features

- **Universal transmutator** — drop any supported image, pick output, route to `/transmute/{slug}` with file staged.
- **Registry-driven matrix** — `universal-matrix.ts` from active tools.
- **ArrayBuffer handoff** — in-memory store + `?handoff=` token; Strict Mode–safe consume on destination panel.
- **Visual refresh** — badge, gradient card, larger drop zone.

## Fixes

- Handoff no longer stuck at “Reading file…” or empty dropzone after redirect (React Strict Mode + `prepareId` lifecycle).
- App semver corrected: **3.1.1** (Tier 3.5.x remains documentation phase only).

- `UniversalTransmutator`, `UniversalOutputPicker`, `file-handoff.ts`, `universal-matrix.ts`, `TransmutationPanel` handoff consumer.
