# Camaleon v3.5.0 — Universal Transmutator (Tier 3.5)

**Date:** 2026-06-11  
**Branch:** `dev` → `main`  
**Tag:** `v3.5.0`  
**Engine:** 1.6.0 (unchanged)

## Summary

**3.5.0** adds a **Universal Transmutator** on the home page: drop any supported image, pick from registry-derived outputs, and land on the existing tool route with the file already handed off. No new Wasm crate.

## Features

- **Home drop zone** — isolated drag & drop (no page-wide overlay on `/`).
- **Registry-driven output matrix** — `universal-matrix.ts` from `getActiveTools()`.
- **File handoff** — in-memory `?handoff=` token → `TransmutationPanel` auto-prepare.
- **Auto-redirect** when only one output exists (ICO→PNG, TGA→PNG).
- **EN/ES** copy under `landing.universal.*`.

## Technical

- `UniversalTransmutator`, `UniversalOutputPicker`, `file-handoff.ts`, `universal-matrix.ts`.
- App version **3.5.0**.

## Not in this release

- Command Palette universal entry (v3.5.1).
- HEIC / magic-byte sniffing.
- In-place conversion without navigation.
