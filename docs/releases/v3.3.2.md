# Camaleon v3.3.2 — Offline install promo (home)

**Date:** 2026-06-19  
**Branch:** `dev`  
**Tag:** `v3.3.2`  
**Engine:** 1.6.0 (unchanged)

## Summary

Surfaces Camaleon's **offline / PWA** capability on the home page with a non-blocking floating promo. **Install** deep-links to **Settings → Offline & cache** via the shared `settings-focus` module (scroll + accent pulse).

## Changes

### Offline install promo

- `OfflineInstallPromoNotice` — floating card on home; bottom-left on desktop, centered on mobile.
- `useOfflineInstallPromo` — visibility: home only, SW supported, not standalone PWA, precache not complete, not snoozed.
- `offline-promo-storage.ts` — 7-day snooze in `camaleon-user-settings-v1` (`offline.installPromoSnoozedUntil`).
- **Install** → `openSettings({ focus: "offline" })`.
- **Remind me later** → snooze.
- i18n `offlinePromo.*` (EN/ES).

### Layout

- `FloatingNotices` variant `bottom-left` — separate host from center toasts / app-update notice.
- Styles in `globals.css` (`offline-promo-notice`, `floating-notice-stack--bottom-left`).

## QA exit gate

1. Home `/` while online → promo visible (if precache not done).
2. **Install** → Settings opens, scrolls to Offline & cache, accent pulse.
3. **Remind me later** → promo hidden for 7 days.
4. Complete full toolkit precache → promo stays hidden.
5. Standalone PWA / `display-mode: standalone` → no promo.
6. `npm test` — offline-promo-storage Vitest passes.

## Not in this release

- **4a.1** metrics-first optimize UX
- **UX-4a** ToolBrowser Convert vs Optimize lanes
- Native `beforeinstallprompt` one-click PWA install (promo routes to Settings)
