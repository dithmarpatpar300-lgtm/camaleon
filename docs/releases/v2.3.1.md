# Camaleon v2.3.1 — Settings Panel (S1)

**Date:** 2026-06-11  
**Tag:** `v2.3.1`  
**Wave:** UX — centralized preferences drawer

## Summary

Camaleon **2.3.1** ships the **Settings panel (S1)** — a right-side drawer that consolidates language, theme, and release-comms preferences. Header quick toggles remain; the gear trigger adds discoverability and changelog control.

**Tags:** **NEW** (Settings drawer)

## User-facing

- **Settings drawer** — gear in header `UtilityCluster`; same surface language as What's New
- **General** — language EN/ES, theme Light/Dark (static theme cells — no sliding pill desync)
- **Updates** — toggle release notes on version bump; open What's New; reset welcome message
- **Refined utility cluster** — aligned circular buttons; settings cog with green idle / red open states + rotation
