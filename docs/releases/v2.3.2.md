# Camaleon v2.3.2 — Transmutation Defaults (Settings S2)

**Date:** 2026-06-11  
**Tag:** `v2.3.2`  
**Wave:** UX — global encode defaults in Settings

## Summary

**2.3.2** adds **Settings S2**: persist global transmutation defaults (JPEG quality, PNG compression, AVIF quality/speed, alpha flatten background) and apply them when opening any tool.

## User-facing

- **Settings → Transmutation defaults** — sliders + background swatches
- **Reset to factory** — clears overrides; registry baselines apply again
- New files inherit defaults on prepare; session sliders still override per conversion

## Technical

- `lib/prefs/transmutation-defaults.ts` + `build-default-options.ts`
- Stored in `camaleon-user-settings-v1.transmutation`
- `resolveSpecDefault(tool, spec)` — AVIF quality vs JPEG quality by output format
- Vitest: `npm run test:defaults`

## Versioning

- App **2.3.2** · Engine **1.6.0** (unchanged)
