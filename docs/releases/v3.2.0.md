# Camaleon v3.2.0 — Multi-file batch (Tier 3.6.0)

**Date:** 2026-06-11  
**Branch:** `dev`  
**Tag:** `v3.2.0` (when promoted)  
**Engine:** 1.6.0 (unchanged)

## Summary

First **multi-file batch** release on **dedicated transmutator routes**. Drop several images on supported tools (e.g. PNG → JPEG), adjust shared options once, select which files to convert, and get **one download per result**. Processing is **sequential** (one file at a time) to stay within browser memory limits.

## Strict tool contract (§7.2)

On a dedicated route, only files matching that tool's accepted extensions enter the batch. Incompatible files (e.g. SVG on PNG → JPEG) are **skipped with a notice** — not silently discarded. For **mixed formats in one drop**, use the **Universal transmutator** on the home page (Tier 3.6.1).

## Allowlisted tools (14)

`png-to-jpg`, `jpg-to-png`, WebP/BMP/AVIF/TGA raster routes, `png-to-ico`. GIF, TIFF, ICO→PNG, SVG batch deferred to later phases.

## QA exit gate

1. Open `/transmute/png-to-jpg` (online, dev or preview).
2. Drop **5 PNG** files → batch workspace with 5 rows.
3. Deselect 2 → **Transmute 3** → exactly **3 downloads**.
4. Drop **4 PNG + 1 SVG** → toast notice + batch **4 PNG only**.
5. Single-file flow on any tool unchanged (1 file → existing StagedWorkspace).

## Not in this release

- Universal transmutator multi-drop / cohorts (3.6.1)
- ZIP export (3.6.2)
- Per-row frame/page/entry pickers in batch
