# Camaleon v1.10.0 — TIFF → PNG

**Date:** 2026-06-08  
**Branch:** `dev`

## Summary

First Tier 2 Wave 2 release: archival TIFF support with honest 16-bit normalization, multi-page IFD picker, and palette/CMYK rejection.

## New tool

- **TIFF → PNG** — lossless DEFLATE export from `.tif`/`.tiff` sources

**Eleven active conversion tools** (adds to the v1.9.0 baseline of ten).

## Highlights

- Multi-page TIFF: select one IFD (same UX pattern as GIF frame picker)
- 16-bit and float sources normalize to 8-bit PNG with documented tone mapping
- Wasm `inspect_tiff_meta` drives page scrubber and bit-depth labels
- Astro downscale path applies when megapixels exceed browser limit

## Technical

- New crate: `transmutador_tiff` (~919 KB Wasm, NFR-7 pass)
- Dependencies: `image` 0.25 (`tiff` feature), `tiff` 0.11
- StripAll on output; estimate-first pipeline with `page_index`
