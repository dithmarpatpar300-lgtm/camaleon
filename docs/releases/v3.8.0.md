# Camaleon v3.8.0 — Compress Premium Phase C (PNG lossless optimization)

**Date:** 2026-06-23
**Branch:** `dev`
**Tag:** `v3.8.0`
**Engine:** 1.7.0

## Summary

Native PNG lossless optimization pipeline replacing the planned oxipng integration (spike-gated: libdeflate-sys requires C compiler, not Wasm-viable). Delivers filter trial, color type reduction, bit depth reduction, alpha optimization, and deflate strategy tuning — all with zero external dependencies beyond the existing `image` and `miniz_oxide` crates.

## Highlights

### Filter trial + color type reduction
- Tries 5 PNG filter types (Sub, Up, Avg, Paeth, Adaptive) and picks the smallest output.
- Detects RGBA images with all-opaque alpha → reduces to RGB.
- Detects RGB images where R=G=B for all pixels → reduces to Grayscale (L8).
- Grayscale images now encode correctly as L8 (was incorrectly encoded as RGB — 3× inflation).

### Bit depth reduction
- Pure black & white images → L1 (1-bit, 8 pixels per byte).
- Images with ≤16 unique gray levels → L4 (4-bit, 2 pixels per byte).
- Images with ≤4 unique gray levels → L2 (2-bit, 4 pixels per byte).
- All transformations are lossless — pixel values verified before reduction.

### Alpha optimization
- Transparent pixels (alpha=0) have their RGB channels zeroed.
- Improves DEFLATE compression on RGBA images with large transparent regions.

### Deflate strategy tuning
- Custom PNG encoder using `miniz_oxide` directly with strategy control.
- 3 deflate strategies tried per filter: Default, Filtered, HuffmanOnly.
- `Filtered` strategy designed specifically for pre-filtered PNG data.
- Full PNG container built manually: IHDR + chunked IDAT + IEND + CRC32.

### Pipeline summary (opt_level=1)
```
Input → color_type_reduce → optimize_alpha_pixels
      → 6 image::PngEncoder candidates (Adaptive + 5 filter trial)
      → 15 custom encoder candidates (5 filters × 3 DEFLATE strategies)
      → 15 bit depth candidates (L1/L4/L2 × 5 filters)
      → Output = min(all 36 candidates)
```
