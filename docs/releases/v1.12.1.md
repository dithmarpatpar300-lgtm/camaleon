# Camaleon v1.12.1 — Brand Mark & Favicon Polish

**Date:** 2026-06-09  
**Tag:** `v1.12.1` (patch on `dev`)  
**Wave:** Pre-Tier 3 UI/UX — visual identity completion; no new conversion tools

## Summary

Ships the **Lamina 3 option C** chameleon mark across the product shell: header brand link, transparent browser favicon, and Apple touch icon. Replaces the interim inline SVG crest with reference-faithful PNG assets and a reproducible generation script.

## Categories

| Tag | Scope |
|-----|--------|
| **NEW** | `BrandLink`, `CamaleonMark`, `public/brand/*`, `generate-brand-assets.mjs` |
| **FIX** | Favicon dark-square artifact, flat/clipped head from bad SVG extraction, header mark centering |

## User-facing

- **Header** — Lamina 3C mark + wordmark on all breakpoints; accent hover ring; larger optical frame (`h-10`)
- **Favicon** — transparent tile, centered mark (~80% safe area), no black box in browser tabs
- **Apple touch** — dark `#0E0F11` tile with centered mark (iOS add-to-home)

## Technical

- `frontend/src/components/brand/BrandLink.tsx`, `CamaleonMark.tsx`
- `frontend/public/brand/camaleon-mark.png` (+ 64/128 variants), `reference-dark.png`
- `frontend/src/app/icon.png`, `apple-icon.png`
- `frontend/scripts/generate-brand-assets.mjs` — trim, center, extract from reference
- `Header.tsx` — `BrandLink` replaces inline SVG
