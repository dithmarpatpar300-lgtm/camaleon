# Camaleon v2.3.3 — Performance (Settings S3)

**Date:** 2026-06-11  
**Tag:** `v2.3.3`  
**Wave:** UX — adaptive performance overrides in Settings

## Summary

**2.3.3** adds **Settings S3**: override adaptive resource tier, result cache, and auto-estimate behavior without reloading the app.

## User-facing

- **Settings → Performance** — tier (Auto / Conservative / Balanced / Aggressive)
- **Result cache** — Auto / On / Off for slider re-encode paths
- **Auto-estimate** — Auto / On / Off when options change
- **Reset to adaptive** — clears overrides; device signals drive behavior again

## Technical

- `lib/prefs/performance-prefs.ts` — `applyPerformancePrefs`, `subscribePerformancePrefs`
- `buildResourceProfileForTier` extracted from `computeResourceProfile`
- `useAdaptiveResourceProfile` applies prefs live on Settings change
- Stored in `camaleon-user-settings-v1.performance`
- Vitest: `npm run test:performance`

## Versioning

- App **2.3.3** · Engine **1.6.0** (unchanged)
