# Camaleon v3.2.6 — Update detection in Settings

**Date:** 2026-06-11  
**Branch:** `dev`  
**Tag:** `v3.2.6` (when promoted)  
**Engine:** 1.6.0 (unchanged)

## Summary

Choose whether Camaleon **automatically checks Live** for new versions, or run a **manual check** from Settings when you prefer.

## Changes

### Updates settings section

- **`UpdatesSettingsSection`** — extracted from inline Settings drawer markup.
- **Auto-detect updates** toggle (`updates-prefs.ts`, default ON).
- **Check now** button — immediate Live poll when auto-detect is off (or on demand).
- Toasts for up-to-date, update found, offline, and production-only messages.

### App update provider

- `AppUpdateProvider` respects `autoDetectUpdates` — no interval/visibility/online poll when OFF.
- Passive SW `waiting` listener kept for already-downloaded updates.

## QA exit gate

1. Settings → Updates → turn auto-detect OFF → no background poll; Check now still works on Live.
2. Check now in dev → friendly “production only” toast.
3. Check now on Live when up to date → success toast.
