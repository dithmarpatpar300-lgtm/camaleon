# Camaleon v3.3.0 — Tier 4a activation & PWA icon fix

**Date:** 2026-06-19  
**Branch:** `dev`  
**Tag:** `v3.3.0`  
**Engine:** 1.6.0 (unchanged)

## Summary

Activates **Tier 4a** image optimization end-to-end (four compress/resize tools) and fixes PWA manifest icons to match the Lamina 3C brand mark at the declared pixel sizes.

## Changes

### Tier 4a.0 — Optimize activation

- `warmup-wasm.ts` — `transmutador_optimize` case in prepare warmup (fixes `Unknown module` at prepare).
- `wasm-modules.d.ts` — typed exports for `recompress_*`, `resize_*`, `estimate_*`, session/risk.
- `source-image-meta/index.ts` — `JPEG` alias alongside `JPG` for optimize tool dimension probes.
- `warmup-wasm.test.ts` — registry ↔ warmup coverage regression.
- `format-alias.test.ts` — JPEG optimize prepare meta probe.

### PWA icons

- `generate-brand-assets.mjs` — emits `public/pwa/icon-192.png`, `icon-512.png`, `icon-512-maskable.png` from the same reference pipeline as favicon/apple-icon.
- `manifest.ts` — dedicated maskable asset (safe-zone padding); fixes Chrome “Resource size is not correct” when legacy placeholders did not match declared sizes.

## QA exit gate

1. `/transmute/png-compress` — drop → prepare → estimate → transmute → valid PNG download.
2. `/transmute/jpg-compress`, `png-resize`, `jpg-resize` — same flow.
3. DevTools → Application → Manifest — no icon size warnings; 192×192 and 512×512 validate.
4. `npm test` — 124+ Vitest tests pass.
