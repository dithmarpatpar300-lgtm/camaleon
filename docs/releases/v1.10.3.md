# Camaleon v1.10.3 — PNG → ICO

**Date:** 2026-06-08  
**Branch:** `dev`  
**Wave:** Tier 2 — Wave 2, Phase 7.4

## Summary

Adds **PNG → ICO** — build a single-resolution Windows favicon from PNG with honest downscale-only sizing.

## User-facing

- New tool **`/transmute/png-to-ico`** — accepts `.png`
- **Icon size presets:** 16, 32, 48, or 256 px (default 256)
- **Downscale only:** sources smaller than the preset keep their native dimensions; never upscaled
- Output: modern **PNG-in-ICO** (single directory entry)

## Technical

- `transmutador_ico`: `ico_encode.rs` — `transmutar_png_a_ico`, `estimate_png_to_ico_size`
- Lanczos3 downscale when `max(w,h) > target_size`
- `IcoEncoder::write_image` with RGBA8
- Worker route `isPngToIco`; MIME `image/x-icon`
- **14 active tools** (onboarding + What's New updated)

## Tests

- `png_to_ico_round_trip` — PNG → ICO → PNG entry decode
- `png_to_ico_no_upscale` — 32×32 source at 256 preset stays 32×32
