# Camaleon v3.7.0 — Compress Premium Phase A

**Date:** 2026-06-23
**Branch:** `dev`
**Tag:** `v3.7.0`
**Engine:** 1.6.1

## Summary

Compress Premium Phase A — honesty notices, color type preservation fix, and default alignment for `png-compress` and `jpg-compress`. This release lays the UX foundation for all subsequent Compress Premium phases.

## Highlights

### Honesty notices for compress
- **JPEG generational loss warning** — now shows for both `jpg-compress` and `jpg-resize` (unified). Warns users that re-encoding a JPEG adds another lossy generation.
- **PNG compress speed/quality hints** — fast compression (level ≤3) warns about potential size increase; slow compression (level ≥8) confirms lossless pixel identity.
- **Size increase warning** — when the estimate exceeds the input file size, a notice fires: "Try a higher compression level to reduce file size."

### Color type preservation fix
- `encode_png` now preserves the source image's color type — RGB stays RGB, RGBA stays RGBA. Previously all output was forced to RGBA, which inflated files by 33% when the source had no alpha channel.
- Engine bumped to **1.6.1** for this Rust-level change.

### Default alignment
- Worker fallback defaults aligned with registry (PNG compression=9, JPEG quality=75).
- JPEG compress default quality raised to 85 with balanced preset at 85, high at 95.

### i18n
- Four new notice keys added in both EN and ES: `jpegGenerational`, `pngCompressFast`, `pngCompressSlow`, `compressLarger`.
