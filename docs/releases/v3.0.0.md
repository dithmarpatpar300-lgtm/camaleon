# Camaleon v3.0.0 — PWA / Offline Shell (Tier 3 capstone)

**Date:** 2026-06-11  
**Branch:** `dev` → `main`  
**Tag:** `v3.0.0`  
**Engine:** 1.6.0

## Summary

**3.0.0** closes **Tier 3** with a **Progressive Web App (PWA)** shell: Service Worker caching, offline UX, and **Settings S5** opt-in to download all Wasm conversion engines. Transmutation remains 100% client-side (NFR-1).

## Features

- **PWA manifest + Serwist Service Worker** — precache app shell, 21 tool routes, legal pages; `CacheFirst` for `/wasm/**`.
- **Offline UX** — connectivity banner, `/~offline` fallback, uncached-tool notice, controlled SW update prompt (`skipWaiting: false`).
- **Settings S5 — Offline & cache** — opt-in “Download all conversion tools” (~10–17 MB Cache Storage); storage estimate + clear cache.
- **NFR-9 offline shell** — documented in SPEC; first online visit required; cached tools work without network.

## Technical

- Frontend: `@serwist/next`, `sw.ts`, `OfflineProvider`, `OfflineSettingsSection`, `precache-toolkit.ts`, `wasm-crates.ts`.
- Docs: `tier3_4_pwa_implementation_plan.md`, DEPLOY.md PWA QA section, privacy policy cache disclosure.

21 active conversion tools · 12 Wasm crates · AVIF + SVG + PWA offline shell.
