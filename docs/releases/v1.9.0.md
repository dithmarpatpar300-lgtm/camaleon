# Camaleon v1.9.0 — Tier 2 Wave 1

**Date:** 2026-06-08  
**Tag:** `v1.9.0`

## Summary

Tier 2 Wave 1 complete: GIF and BMP conversion suites, premium polish, adaptive safety limits, client-side downscale for large science imagery, and Wasm worker memory lifecycle for stable long sessions.

## New formats (4 tools)

- **GIF → PNG / GIF → JPEG** — animated frame picker, GIF89a compositing, live preview
- **BMP → PNG / BMP → JPEG** — semantic alpha detection, PNG growth warnings, Wasm header probe

**10 active conversion tools** total (JPG, PNG, WebP, GIF, BMP families).

## Improvements

- **Adaptive limits** — 50 MB soft consent zone, 150 MB hard ceiling, 40 MP pixel cap
- **`LimitContext`** — unified gating for estimate, transmute, and consent flows
- **Source image meta** — dimensions, bit depth, frame count in workspace
- **Unified prepare gate** — crossfade into staged workspace with progress phases
- **Science imagery path** — client-side downscale (4K–8K presets) when megapixels exceed browser limit
- **Precise error messages** — dimension and size errors fully localized (EN/ES)

## Fixes

- Large-file quality slider now re-estimates output size on change
- 12K resize preset disabled when target exceeds 40 MP
- Scrollbar uses default cursor (no grab hand)
- **Memory:** Wasm worker recycled when leaving any `/transmute/*` route — RAM no longer stuck at 2+ GB until F5

## Technical

- Engine: Rust workspace v1.4.2 — `transmutador_gif`, `transmutador_bmp`
- Frontend: Next.js 15, Web Workers, `workerEpoch` recycle pattern
- Privacy unchanged: 100% client-side, StripAll metadata default
