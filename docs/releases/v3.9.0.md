# Camaleon v3.9.0 — Tier 4a.2a WebP Compress

**Date:** 2026-06-24
**Branch:** `dev`
**Tag:** `v3.9.0`
**Engine:** 1.8.0

## Summary

First tool in the Tier 4a.2 Matrix Expand — WebP lossless VP8L re-encode with predictor transform toggle, color type optimization, and honest lossy-source warnings. Extends the optimize ladder beyond PNG/JPEG to WebP format.

## Highlights

### WebP Compress tool (`webp-compress`)
- New optimize tool: WebP → WebP same-format re-encode via VP8L lossless.
- `image-webp` crate (pure Rust, MIT/Apache) integration — zero C dependencies, Wasm-viable.
- Predictor transform toggle (VP8L spatial predictor on/off).
- Optimization level 1 (Full): tries both predictor settings + color type reduction (RGBA→RGB), picks smallest.
- Animated WebP hard-rejected with error (no silent frame loss).
- Lossy WebP sources accepted with amber warning (entropy expansion doctrine — same as JPG→PNG §5.4.2).
- Deep-link suggestion to WebP→JPG for lossy source size reduction.

### Honesty notices
- `webpLossySource` — amber warning when source is lossy VP8 (size will increase).
- `webpLosslessSource` — info when source is lossless VP8L (re-optimized).
- `webpMetadataStripped` — info: EXIF/XMP/ICC stripped per privacy policy (§5.10).
- `compressLarger` — extended to include `webp-compress` (output larger than input warning).
- `webpCompressLosslessLimit` — new conditional notice: fires when lossless WebP delta is near zero, explains VP8L compression ceiling.

### VP8X recursive probe (bug fix)
- `probe_webp_format` in both Rust and TypeScript now recursively scans VP8X extended containers for inner VP8/VP8L chunks.
- Lossy-source amber notice now correctly fires for VP8X files (most camera photos converted externally).

### EXIF orientation auto-apply (bug fix)
- `JpegDecoder::orientation()` + `apply_orientation()` added across 3 crates: transmutador_encode (JPEG→WebP), transmutador_optimize (jpg-compress/resize), transmutador_jpg (JPEG→PNG).
- Phone camera photos (S25 Ultra, iPhone) no longer display rotated — EXIF tag is read before decode, applied to raster, then StripAll removes the tag safely.

### UI/UX clarity improvements
- All 3 WebP tool fidelity hints updated with explicit size inflation language.
- `webpLossySource` notice improved: adds "(entropy expansion — same as JPEG→PNG)" for user recognition.
- `webpLosslessSource` notice improved: explains VP8L compression ceiling.
- New conditional notice fires for lossless WebP at compression limit.

### core_utils WebP format probe
- `WebpFormat` enum: `Lossy`, `Lossless`, `Extended`.
- `probe_webp_format(bytes)` — pure byte-level RIFF chunk parsing, no decode.
- Used by prepare pipeline to surface honest notices before transmute.
