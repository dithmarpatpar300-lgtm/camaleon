# Camaleon v1.10.1 — TIFF → JPEG

**Date:** 2026-06-08  
**Branch:** `dev`

## Summary

Lossy web export from archival TIFF — quality slider, background flattening for alpha, and the same multi-page picker as TIFF → PNG.

## New tool

- **TIFF → JPEG** — compress scans and print masters for sharing online

**Twelve active conversion tools.**

## Highlights

- JPEG quality presets (Web / Balanced / High) with live size estimate
- Per-page alpha detection updates background picker when switching IFDs
- 16-bit sources normalize to 8-bit before JPEG encode (honesty copy in UI)

## Technical

- Extends `transmutador_tiff` with `transmutar_tiff_a_jpg_with_options` + `estimate_tiff_to_jpg_size`
- `flatten_rgba_on_background` (same pattern as BMP → JPEG)
- Release Comms manifest entry `v1.10.1` + onboarding updated to 12 tools
