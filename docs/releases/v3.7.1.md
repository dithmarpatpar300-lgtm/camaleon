# Camaleon v3.7.1 — Compress Premium Phase B (JPEG encoder swap)

**Date:** 2026-06-23
**Branch:** `dev`
**Tag:** `v3.7.1`
**Engine:** 1.7.0

## Summary

JPEG encoder swap — replaced `image::JpegEncoder` with the `jpeg-encoder` crate (pure Rust, +18 KB Wasm). All JPEG encode paths (compress + resize) now use optimized Huffman tables by default, yielding 5-15% smaller files at the same visual quality. New chroma subsampling control for `jpg-compress` with 4:2:0 (Auto), 4:2:2, and 4:4:4 modes.

## Highlights

### JPEG encoder swap (jpeg-encoder crate)
- `image::JpegEncoder` replaced with `jpeg_encoder::Encoder` (pure Rust, MIT/Apache-2.0, wasm-compatible, 39 KB crate).
- **Optimized Huffman tables enabled by default** — all JPEG encodes (compress and resize) produce 5-15% smaller files at the same quality without any user configuration.
- New Wasm exports: `recompress_jpeg_with_options(input, quality, chroma_code)` and `estimate_jpeg_recompress_with_options()`.
- Backward compatible: `recompress_jpeg(input, quality)` unchanged.
- +18.5 KB Wasm delta (672 KB total — well within NFR-7 3 MB limit).

### Chroma subsampling control
- New slider on `jpg-compress`: Auto (4:2:0) / 4:2:2 / 4:4:4.
- 4:2:0 = best compression for photos (default). 4:4:4 = highest color fidelity for text/screenshots.
- Fidelity notice fires when 4:4:4 is selected: explains trade-off.

### Verification
- 7 Rust integration tests (new: subsampling order, JPEG roundtrip, color type preservation).
- 183 Vitest tests pass.
- Wasm binary builds for all 13 crates.
