# Camaleon v3.5.0 — Offline reliability & connectivity hardening

**Date:** 2026-06-20  
**Branch:** `dev` → `main`  
**Tag:** `v3.5.0`  
**Engine:** 1.6.0 (unchanged)

## Summary

**Stable offline baseline** after v3.4.0. This release consolidates deep PWA persistence work and a new **origin reachability** layer so connectivity UX is honest across localhost, Cloudflare tunnel, and real network loss — without false “offline” when the server is live, and without broken header branding when navigating offline.

> **Note:** Work started as v3.4.1 on `dev`; shipped to production as **v3.5.0** because the scope grew into new infrastructure (health probes, hysteresis, cache-first brand assets, unified mobile notice stack).

## Highlights

### Offline persistence (from v3.4.1 scope)

- **Dual readiness:** Settings reports **app shell** and **Wasm engines** separately; Offline Mode gated until both are ready.
- **App update fix:** `applyAppUpdate()` no longer purges active Serwist precache post-activate.
- **Shell recovery:** `reprecacheAppShell()`, `ShellCacheBootstrap`, auto-reprecache after clear cache when online.
- **Force-offline aligned:** SW + `network-guard` serve `/~offline` and pathname cache scan before 503.

### Connectivity & origin reachability (v3.5.0)

- **`GET/HEAD /api/health`** — dedicated liveness endpoint (`no-store`).
- **`origin-reachability.ts`** — multi-probe fallback (`/api/health`, `/version.json`, `/manifest.webmanifest`) with **hysteresis** (2 failures → offline, 1 success → online); optimistic default avoids tunnel/RSC blips.
- **SW `NetworkOnly`** for `?camaleon-probe` requests — probes never served from cache.
- **`network-guard`** — captures native `fetch` before bridge install; no longer infers server down from app fetch failures.

### Brand mark & real offline navigation (v3.5.0)

- **SW cache-first listener** for `/brand/*` and shell static assets — registered **before** Serwist precache (fixes logo loss on route change in real offline vs force-offline-only path).
- **`CamaleonMark`** — plain `<img>` to `/brand/camaleon-mark.png` (no `/_next/image` pipeline).
- **Shell reprecache** explicitly caches brand PNGs + parses brand `src` from HTML.

### Mobile notice stack (v3.5.0)

- Single **bottom dock** on narrow viewports: toasts → offline status → install promo → app update (column-reverse, gap).
- Bottom-left promo host **desktop only** — eliminates overlap/clash on mobile.

### Legal UI polish (v3.5.0)

- **`LegalTable`** component + improved **`LegalToc`** for Privacy/Terms storage tables.

## QA exit gate

1. **`npm run preview:cf`** + tunnel: server live → green dot, no false offline toast.
2. Cut internet (or stop server): offline within ~15–30s; “Working offline” copy (not testing mode).
3. Real offline via tunnel: navigate `/` ↔ `/transmute/*` → **header logo persists**.
4. Force offline (Settings): same logo + navigation behavior.
5. Mobile: multiple bottom notices **stack vertically**, no overlap.
6. Clear cache → reprecache shell → offline F5 on `/` and tool routes.
7. App update → offline F5 → shell intact (P0 regression).
8. **`npm test`** — 179+ Vitest tests pass.
