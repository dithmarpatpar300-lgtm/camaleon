# Camaleon v3.2.7 — Toast notifications & UI polish

**Date:** 2026-06-11  
**Branch:** `dev`  
**Tag:** `v3.2.7` (when promoted)  
**Engine:** 1.6.0 (unchanged)

## Summary

Hotfix and UX release: **centralized toast notifications**, a **floating notice stack** that avoids overlap, and **modal backdrop blur** fixes on production builds — plus v3.2.5 app updates and v3.2.6 Settings update prefs shipped in the same train since v3.2.4.

## Changes

### Toast system (new)

- `ToastProvider` — FIFO queue, max 3 visible, auto-dismiss 4 s.
- `ToastViewport` — PanelScrollFade-style top mask; peek band only when **4+ toasts** queued.
- `ToastCard` / `ToastHost` — success and info variants with dismiss.
- `useToast()` API unchanged for consumers (`UpdatesSettingsSection`, etc.).

### Floating notices

- `FloatingNoticesRoot` — top/bottom hosts on `document.body` (z-index 100).
- `FloatingNoticeStack` — App update pill + toast column without overlap.
- Popover top-layer **promote on toast when a dialog is open**; **demote on close** — toasts above Settings without breaking `::backdrop` blur.

### App updates (v3.2.5 + v3.2.6, included)

- See `docs/releases/v3.2.5.md` and `docs/releases/v3.2.6.md`.

### UI fixes

- Modal `::backdrop` blur restored on `preview:cf` / Live (no full-screen popover on dialog open).
- Toast veil peek: mask-only fade (no opaque overlay); correct behavior with Settings open and with 1–3 toasts.

## Tests

- 105 Vitest tests passing (`lib/toast`, `lib/app-update`, `lib/prefs/updates-prefs`, etc.).

## QA exit gate

1. Settings → Check now → toast visible above open drawer; backdrop blurred behind panel.
2. Four rapid Check now clicks → 4th toast peeks with top fade; single toast — no ghost/shadow.
3. Live tab with pending SW update → pill + toasts coexist without overlap.
4. Close Settings → toasts and pill behave on main page.
