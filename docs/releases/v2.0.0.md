# Camaleon v2.0.0 — Tier 3 begins (AVIF decode, Phase 3.1.0–3.1.1)

**Date:** 2026-06-11  
**Tag:** `v2.0.0`  
**Wave:** Tier 3 — Modern Image Formats (first major release line after v1.x)

## Summary

Camaleon **2.0.0** opens the v2 product line with **AVIF decode** — the first Ladder B modern format. This release ships Tier 3 **Phase 3.1.0** (spike + `transmutador_avif` crate) and **Phase 3.1.1** (AVIF → PNG tool, estimate, worker, UI). **16 active conversion tools.**

Includes hotfixes for the **byte/pixel limit pipeline** and **astro downscale** path so large science PNGs (124 MB / 123 MP) work end-to-end again. Reference: `docs/LIMIT_PIPELINE.md`.

**Next on `dev`:** Phase **3.1.2** — AVIF → JPEG.

## Categories

| Tag | Scope |
|-----|--------|
| **FEATURE** | AVIF → PNG; animated AVIF frame scrubber; `transmutador_avif` (zenavif) |
| **FIX** | Limit/session pipeline; prepare skips full decode >40 MP; post-resize alpha assess session limit |
| **COMPAT** | MIAF `mif1` major brand normalization; AVIF-specific i18n errors |

## User-facing

- **New tool:** AVIF → PNG (`/transmute/avif-to-png`) — compression slider, estimate, StripAll
- **Animated AVIF:** frame scrubber (lazy preview, non-blocking prepare)
- **Large files:** 150 MB elevated zone + 40 MP astro downscale (4K–12K) restored and documented
- **What's New:** v2.0.0 entry in release drawer + onboarding updated to **16 tools**

## Technical

### Engine (`motor_transmutacion` v1.5.0)

- New crate **`transmutador_avif`** — zenavif decode, probe, estimate, session limits
- `avif_container.rs` — `normalize_avif_input` for MIAF/`mif1` interop
- `avif_session.rs` — optional full-frame session (scrubber uses lazy `decode_avif_preview_png`)
- `avif-diagnose` CLI bin for container/decode debugging
- Workspace: ten Wasm crates + `core_utils`

### Frontend

- `AvifFrameScrubber`, prepare flow, worker `frame_index` routing
- `extractWasmError` for wasm-bindgen string errors
- `sessionLimitForBytes` + assess auto-limit; prepare pixel guard
- `docs/LIMIT_PIPELINE.md` — regression reference for limits/astro/AVIF
