# Camaleon v3.2.4 — Universal multi-file drop (same format)

**Date:** 2026-06-11  
**Branch:** `dev`  
**Tag:** `v3.2.4` (when promoted)  
**Engine:** 1.6.0 (unchanged)

## Summary

The **Universal transmutator** on the home page now accepts **multiple files of the same format** — pick a batch output once and land on the matching tool route with all files ready to convert.

## Changes

### Universal homogeneous batch

- Drop or browse **N files** (e.g. 5 JPG) on the home page Universal transmutator.
- UI shows family, file count, and batch-eligible output options (PNG, WebP, AVIF…).
- Navigates to the tool route via **batch handoff** (`?batch=`).

### Batch handoff infrastructure

- `batch-handoff.ts` — stage/consume multi-file payloads (60 s TTL, size guards).
- `buildCohorts` / `resolveUniversalDrop` — registry-driven cohort logic.
- `TransmutationPanel` consumes `?batch=` alongside existing `?handoff=`.

### Mixed formats

- Drop **different formats** in one gesture (e.g. 4 PNG + 1 JPEG) → clear hint; mixed cohort picker deferred to next release.

## QA exit gate

1. Home: drop 5 JPG → pick JPG→PNG → batch workspace on `jpg-to-png`.
2. Home: drop 1 PNG → unchanged single-file Universal flow.
3. Home: drop 4 PNG + 1 JPEG → hint toast, no navigation.
4. Tool route direct drop → no regression (3.2.3 batch).

## Not in this release

- Universal **mixed-format** cohort picker (remaining groups stay on home)
- ZIP export, GIF/TIFF batch per-row options
