# Camaleon v3.8.1 — Compress Premium Phase D (lossy PNG quantization)

**Date:** 2026-06-23
**Branch:** `dev`
**Tag:** `v3.8.1`
**Engine:** 1.7.0

## Summary

Lossy PNG quantization via `quantette` crate — palette reduction and FloydSteinberg dithering. Indexed PNG encoding via the `png` crate. 60-80% size reduction for photographic PNGs at the cost of irreversible quality change. Fixed `Colors: u8 → u16` bug (256 truncated to 0 at Wasm boundary). Updated tool descriptions for both `png-compress` and `jpg-compress`.

## Highlights

### Lossy PNG quantization (quantette)
- Wu's color quantization method + FloydSteinberg error diffusion dithering.
- Configurable palette size: 2 to 256 colors.
- Indexed PNG format via `png::Encoder` (ColorType::Indexed, BitDepth::Eight).
- Typical reduction: 60-80% smaller for photographic content.
- Mandatory `warn` notice: "Visual quality is permanently changed — irreversible."

### Bug fix: Colors: u8 → u16
- The `recompress_png_lossy` Wasm export used `colors: u8` which truncates 256 to 0.
- Changed to `colors: u16` — 256 now arrives correctly.
- Regression: png-compress with lossyColors=256 now works.

### Updated tool descriptions
- `png-compress`: now mentions lossless optimization pipeline + optional lossy quantization.
- `jpg-compress`: now mentions optimized Huffman tables + chroma subsampling control.
