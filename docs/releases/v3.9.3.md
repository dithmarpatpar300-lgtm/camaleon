# Camaleon v3.9.3 — Wasm Sync Engine + S5 Offline Settings Redesign

**Date:** 2026-06-26
**Branch:** `dev`
**Tag:** `v3.9.3`
**Engine:** 1.8.0

## Summary

A new centralized Wasm change-detection system ensures users always have the latest conversion engines. The Settings → Offline & cache section has been completely redesigned with a modern, minimalist layout using the same SettingsRow pattern as the rest of the settings drawer.

## Highlights

### Wasm Sync Engine
- New `useWasmSyncEngine()` hook detects stale cached Wasm engines by comparing a deployed `wasm-manifest.json` buildId against the last-synced buildId stored in preferences.
- State machine: `idle → checking → up_to_date | stale → syncing → up_to_date | error`
- Auto-detect toggle (default on) checks for changes when opening Settings. Manual "Update engines" and "Check now" buttons always available.
- When stale, one click purges the old Wasm cache and re-downloads all 13 engines — no app update needed.

### Build-time manifest generation
- `build-wasm.mjs` now generates `wasm-manifest.json` with engine version, SHA-256 content-hash buildId, per-crate sizes, and total Wasm size.
- The manifest is fetched at runtime with `no-store` to always reflect the latest deploy.

### Cache name centralization
- `WASM_CACHE_NAME` moved to a single source of truth (`lib/wasm/wasm-cache-constants.ts`), eliminating drift between `sw.ts`, `cache-status.ts`, and `app-update/constants.ts`.

### S5 "Offline & cache" redesign
- Complete UI refresh using the `SettingsRow` pattern — consistent with S2–S8 sections.
- Compact status card with gradient background, connectivity dot with glow, and refined badge pills.
- Cache overview stat grid: three blocks (engines, shell, storage) with inline progress bars.
- Engine sync status row with colored badges and action buttons.
- Auto-detect toggle, full toolkit download, offline mode, and maintenance row.
- Removed: redundant hero card, separate StatCard grid, mobile warning banner, fire test card.

### New preferences
- `offline.wasmSyncEnabled` — auto-detect toggle (default true)
- `offline.lastKnownWasmBuildId` — last synced manifest buildId
- `offline.lastWasmSyncAt` — ISO timestamp of last successful sync
