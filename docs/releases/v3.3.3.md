# Camaleon v3.3.3 — Tool lanes, mobile notices & Settings deep-links

**Date:** 2026-06-19  
**Branch:** `dev`  
**Tag:** `v3.3.3`  
**Engine:** 1.6.0 (unchanged)

## Summary

Ships **UX-4a** discovery lanes (Convert vs Optimize), fixes **mobile collision** between top offline notices and the sticky ToolBrowser toolbar, and extends **settings-focus** to uncached Wasm engines.

## Changes

### Mobile notice coexistence

- `useTopFloatingNoticeOffset` — `ResizeObserver` + `MutationObserver` on the top floating-notice host publishes `--layout-top-notice-height`.
- `.tool-browser-sticky` — `top` includes the notice height so the toolbar sticks below offline/server-down toasts on scroll.
- Mobile (`max-width: 639px`) — top-right notice stack spans full width below the header (desktop keeps narrow top-right pill).

### UX-4a — Tool lanes

- `tool-lanes.ts` — `convert` | `optimize` filter, localStorage `camaleon.tools.lane.v1`.
- **ToolBrowser** — segmented lane control above family tabs; Coming soon hidden on Optimize lane.
- **Command palette** — same lane chips; optimize search aliases (`compress`, `resize`, …) in `filter-tools.ts`.
- i18n `landing.tools.lanes.*`, `commandPalette.lanes.*` (EN/ES).

### Settings-focus expansion

- `SettingsFocusLink` — reusable CTA → `openSettings({ focus })`.
- `UncachedToolNotice` — **Open Offline & cache in Settings** deep-link when Wasm is not cached.

## QA exit gate

1. Mobile viewport: enable offline mode or stop dev server → scroll to **Available transmutations** — notice and sticky toolbar do not overlap.
2. Desktop: offline notice stays top-right; toolbar centered — no regression.
3. ToolBrowser **Optimize** lane shows 4 tools; **Convert** shows 21.
4. Command palette lane chips sync with browser; search “compress” finds optimize tools.
5. Uncached tool route offline → notice with link → Settings opens on Offline & cache with pulse.
6. `npm test` passes.
