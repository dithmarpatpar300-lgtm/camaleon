# Camaleon v1.12.2 — Estimation Engine Performance (Pre²-Tier 3)

**Date:** 2026-06-11  
**Tag:** `v1.12.2` (patch on `dev`)  
**Wave:** Pre²-Tier 3 — estimation engine fix + performance; no new conversion tools

## Summary

Fixes and improves the **estimation engine** end-to-end: faster GIF inspect/decode, prepare-time alpha hints to skip redundant scans, multi-entry result cache for quality sliders, centralized flatten with SIMD-friendly paths, Wasm SIMD128 + LTO release profile, and SIMD alpha raster scan.

## Categories

| Tag | Scope |
|-----|--------|
| **FIX** | GIF `inspect_gif` no longer full-decodes all frames; incremental `composite_gif_frame` to target index only |
| **IMPROVE** | Alpha hint (prepare → worker), LRU multi-entry result cache, `flatten_rgba` in `core_utils`, SIMD128 build + alpha scan |

## User-facing

- **Faster estimates** — especially animated GIFs and large images when adjusting quality/compression
- **Smoother sliders** — mid/high-tier devices cache several recent estimate results (LRU)
- **Same exact sizes** — estimate still matches transmute byte-for-byte (doctrine unchanged)
