# Camaleon v3.2.5 — Smart app updates

**Date:** 2026-06-11  
**Branch:** `dev`  
**Tag:** `v3.2.5` (when promoted)  
**Engine:** 1.6.0 (unchanged)

## Summary

Camaleon detects new **Live** releases in the background and applies them with a **deep refresh** — no stale tabs or superficial reloads.

## Changes

### App update module

- `/version.json` beacon (`no-store`) + service worker poll every 5 min + visibility/online hooks.
- `skipWaiting` → wait for `controllerchange` → purge app shell cache (Wasm preserved) → hard reload with cache-bust.
- `AppUpdateProvider` centralizes detection and apply flow.

### UI

- **`AppUpdateNotice`** — compact floating pill (Update now / Later 24 h) replaces top **`SwUpdatePrompt`** banner.
- Floating notice hosts portal to `document.body`.

## QA exit gate

1. Deploy to preview:cf; open two tabs; ship newer build → pill appears on older tab.
2. Update now → deep reload; footer version matches Live.
3. Snooze → pill hidden 24 h.

## Not in this release

- User toggle for auto-detect (→ v3.2.6)
- Centralized toast queue (→ v3.2.7)
