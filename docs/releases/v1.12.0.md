# Camaleon v1.12.0 — Visual Identity & Discovery Shell

**Date:** 2026-06-09  
**Tag:** `v1.12.0` (milestone on `dev`)  
**Wave:** Pre-Tier 3 UI/UX — no new conversion tools

## Summary

Major **visual identity** and **discovery shell** milestone before Tier 3 format expansion. Replaces the landing accordion with a scalable tool browser, unifies overlay surfaces, refreshes transmute tool pages, and ships mobile hotfixes discovered during QA (Huawei P30, scroll-lock, modal portal race).

## Categories

| Tag | Scope |
|-----|--------|
| **NEW** | Surface system, ToolBrowser v2, Command Palette v2, AmbientBloom, transmute-shell, ToolPageHeader |
| **FIX** | What's New close sync, scroll-lock stuck, modal invisible+locked, tab-filter overlap, veil-shadow |
| **PERF** | Mobile bloom tier (no drift, smaller blur), solid subnav on mobile (no backdrop-filter) |

## User-facing

- **Landing** — family tabs + compact rows + density toggle; toolbar hierarchy; light/dark parity
- **Command Palette** — search filter, grouped sections, mobile full-sheet, 44px rows
- **Overlays** — `SurfaceDialog` / `SurfaceSheet`; readable scrims; onboarding/palette/release notes unified
- **Transmute pages** — format chip header, accent dropzone, raised workspace shell
- **Ambient** — compact corner accent glows (desktop + mobile-safe tier)
- **What's New** — header reappears instantly on close; scroll no longer stuck
