**Date:** 2026-06-23

## Summary

Final phase of the Compress Premium pipeline — Zopfli archival compression for extreme PNG size reduction and progressive JPEG scan support. The Compress pipeline A–E is now complete.

## Highlights

### Zopfli archival compression (PNG)
- `zopfli` crate (pure Rust, Apache-2.0) integration for exhaustive DEFLATE compression.
- 3-8% additional size reduction beyond standard Level 9 DEFLATE.
- Extremely CPU-intensive — 10-100× slower than standard encoding.
- Added as `opt_level=2` ("Archival") on `png-compress` — clearly labeled.
- Notice warns: "minutes for large images. Recommended only for long-term storage."

### Progressive JPEG
- Progressive scan JPEG via `jpeg-encoder` `set_progressive(true)`.
- Toggle on `jpg-compress`: Baseline vs Progressive.
- File size is similar to baseline — progressive affects loading behavior, not compression.
